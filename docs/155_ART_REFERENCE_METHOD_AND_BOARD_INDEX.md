# 155 — Art Reference Method and Visual Board Index

**Status:** ACTIVE / SUPPORTING ART AUTHORITY  
**Parent:** `docs/154_STILLRING_ART_BIBLE.md`  
**Purpose:** define how Stillring uses external visual references and how visual boards support, but do not replace, written authority.

---

# 1. Governing rule

Stillring uses reference art to answer design questions.

It does not use reference art as a copying target.

The written Art Bible is authoritative. Visual boards are explanatory evidence for humans and agents.

If a board and `docs/154_STILLRING_ART_BIBLE.md` conflict, the written authority wins until the owner explicitly changes the written authority.

Where a later specific written authority intentionally completes an earlier placeholder, the later specific authority controls that detail. For principal character identity this means `docs/158_CHARACTER_PRODUCTION_MANIFEST.md` controls the specific character facts while `docs/154` continues to control overall character doctrine.

---

# 2. Why boards exist

A visual board should make one bounded production question easier to answer.

Examples:

- What does “playable fantasy illustration” mean in broad value/composition terms?
- How far can geography be exaggerated before settlement logic is lost?
- What degree of character stylization remains grounded?
- How does one region differ from another without relying only on color?
- What does Hush transformation change besides hue?
- How should a gameplay-critical object separate from a dense environment?

A board is not useful merely because it contains attractive images.

---

# 3. Reference extraction protocol

For every external artwork, game screenshot, photograph, architectural reference, film still, painting, or generated image used in production discussion, record the **abstract property being studied**.

Use this pattern:

## Reference
Artist/work/source identifier.

## Question
What production problem are we studying?

## Extracted principle
The generic visual/design idea we want to understand.

## Stillring translation
How Stillring expresses that principle using its own world, geometry, materials, culture, story, and gameplay.

## Forbidden carryover
What recognizable expression must not be copied.

Example:

**Question:** How can a distant town remain readable inside dense vegetation?  
**Extracted principle:** Separate the settlement into a large coherent light/value mass and use oversized natural framing.  
**Stillring translation:** Rootmere may use warm inhabited clusters under massive root/canopy framing, with route structures clearly separated from wet woodland values.  
**Forbidden carryover:** copying a specific painting's tree silhouette, house layout, bridge placement, palette, or brushwork.

# 4. Initial DeviantArt study — extracted principles only

The first visual exploration used selected fantasy-environment work found through DeviantArt. These artists are not style targets. Their work was useful because individual pieces illustrated different production principles.

## Erik Taberman

Useful extracted principles:

- simplified large environment masses;
- strong distant readability;
- restrained surface noise;
- paths and architecture used as compositional guides;
- settlements readable as coherent shapes at distance.

Stillring translation:

- reduce high-frequency background detail before reducing landmark strength;
- compose routes before dressing surfaces;
- ensure a settlement remains legible from approach vistas.

Do not copy:

- specific skyline;
- structure placement;
- painting treatment;
- palette;
- tree/ruin design.

## sandara

Useful extracted principles:

- intimate human settlement nested inside very large natural forms;
- fantasy created through scale rather than constant magical ornament;
- warm human-scale life contrasted against enormous environment shapes.

Stillring translation:

- Rootmere and other nature-dominant regions may make ordinary homes feel small but protected inside region-defining natural structures;
- exaggeration should create cultural adaptation, not just spectacle.

Do not copy:

- specific tree-city architecture;
- shrine layout;
- character designs;
- palette or painterly treatment.

## Jeremy Fenske

Useful extracted principles:

- one dominant geographic feature can define an entire settlement;
- environmental spectacle is strongest when daily life adapts around it;
- large water/terrain features can organize navigation and visual memory.

Stillring translation:

- each major settlement should seek a dominant spatial sentence;
- the dominant feature should affect routes, work, architecture, and social space.

Do not copy:

- specific waterfall-village composition;
- building designs;
- bridge arrangements;
- lighting setup.

## Tyler Edlin

Useful extracted principles:

- ruins and architecture can imply traversal through composition;
- bridges, arches, elevation, gaps, and water can lead the eye before UI does;
- monumental forms remain readable when detail is subordinate.

Stillring translation:

- dungeon/ruin art should visibly communicate spatial relationships and traversal opportunities;
- art, level design, and camera composition must be developed together.

Do not copy:

- specific temple layout;
- ruin silhouettes;
- architectural motifs;
- surface treatment.

## Grounded medieval/environment reference work

Useful extracted principles:

- construction logic;
- believable material use;
- weather response;
- drainage/support/service logic;
- signs that ordinary people actually occupy the place.

Stillring translation:

- fantasy structures must still answer practical questions about use, work, circulation, storage, shelter, and maintenance.

Do not copy:

- a particular real or fictional building as a one-to-one environment asset without independent design review.

# 5. Board set required for Stillring

The visual-development package is not one mood board.

It is a set of boards with separate jobs.

## Board 01 — Master Art Direction / North Star

**Status:** CONCEPT BOARD EXISTS IN CHAT ARTIFACT; REPOSITORY BINARY COPY PENDING.  
**Authority:** visual companion to `docs/154_STILLRING_ART_BIBLE.md`; not independent canon.

Must communicate:

- playable fantasy illustration;
- believable materials / exaggerated scale;
- strong silhouettes and landmarks;
- selective detail;
- broad color/emotional script;
- grounded lightly stylized characters;
- material hierarchy;
- camera/composition philosophy;
- do/don't examples.

## Board 02 — Regional Shape Language

Must compare all six major regions plus Cairnspire/Brindle and finale spaces.

For each region show:

- skyline/massing;
- dominant directional lines;
- natural forms;
- architecture massing;
- major landmark type;
- route language;
- Waking/Hush relationship;
- day/night/weather note.

## Board 03 — Character Style Band

**Written source brief:** `docs/164_BOARD_03_CHARACTER_STYLE_BAND_SOURCE_BRIEF.md`  
**Job:** visualization and verification of the locked character authority in `docs/158`; not an identity-selection round.

Must establish and verify:

- anatomy/proportion range;
- face simplification;
- hair treatment;
- costume silhouette;
- hand/tool readability;
- age/body diversity;
- named-character versus population differentiation;
- forbidden uncanny/photoreal boundary;
- principal group silhouette separation;
- Neris's locked female age-17 visual identity and Cantor/equipment integration;
- state continuity and Hush recognition;
- Listener manifestation.

Board 03 may not redesign Neris or any other locked principal identity. If its execution conflicts with `docs/158`, the board fails and must be corrected.

## Board 04 — Lighting / Atmosphere / Time

Must compare:

- dawn;
- daytime;
- dusk;
- night;
- interior workspaces;
- sacred/precise resonance states;
- Hush;
- Stillness;
- weather families.

Purpose: prevent every environment artist from inventing a separate exposure/color philosophy.

## Board 05 — Gameplay Readability

Must demonstrate:

- traversable versus non-traversable structures;
- mantle/ledge/ladder visual language;
- puzzle/mechanism hierarchy;
- target/interactable readability;
- hazards;
- enemy telegraphs at gameplay distance;
- VFX density limits;
- color-independent cues;
- examples of “honest world” affordances.

## Board 06 — Representative Benchmark Scene

Must be created only after the earlier rules are stable enough.

One representative Stillring location should combine:

- final-direction character treatment;
- regional kit;
- landmark composition;
- traversal readability;
- lighting;
- atmosphere;
- props;
- VFX;
- Waking/Hush comparison where appropriate.

This board becomes useful for vertical-slice production quality comparison but does not prove runtime performance.

# 6. Board storage convention

When binary/image repository workflow is available, use a clear non-authority reference tree such as:

`docs/art/boards/`

Suggested filenames:

- `01_MASTER_ART_DIRECTION.png`
- `02_REGIONAL_SHAPE_LANGUAGE.png`
- `03_CHARACTER_STYLE_BAND.png`
- `04_LIGHTING_ATMOSPHERE.png`
- `05_GAMEPLAY_READABILITY.png`
- `06_BENCHMARK_SCENE.png`

Each image should have a neighboring Markdown note explaining:

- purpose;
- date;
- status;
- source/provenance;
- which Art Bible sections it illustrates;
- unresolved questions;
- whether owner-reviewed.

An image file with no explanatory Markdown is not production authority.

# 7. Generated-image policy

Generated imagery may be used for exploration, composition discussion, and rapid visual comparison.

Generated images must not become unexamined final design authority.

Before promoting any generated visual idea, record:

- which written rule it demonstrates;
- which accidental details are noncanonical;
- whether it resembles an existing protected work too closely;
- what must be redesigned by production artists;
- whether gameplay/architecture logic actually works in 3D.

Generated typography, symbols, costume details, props, and architecture should be treated as provisional unless separately specified in repository authority.

For Board 03 specifically, generated imagery must be corrected to match `docs/158` and `docs/164`; it may not use generation variance as permission to alter locked character identity.

# 8. Photographic and real-world research

Real-world reference is encouraged for:

- construction;
- geology;
- forestry;
- water behavior;
- weather;
- tools;
- textiles;
- metallurgy;
- ceramics;
- transport;
- erosion/wear;
- working settlements;
- historical infrastructure.

The purpose is to give fantasy credible roots.

Do not let real-world reference force bland realism when controlled exaggeration better serves Stillring's visual identity.

---

# 9. Game reference policy

Games may be studied for abstract production problems such as:

- readability;
- camera/environment composition;
- regional differentiation;
- traversal affordance communication;
- color hierarchy;
- animation readability;
- density control;
- landmark navigation.

Do not use another game as a direct visual target.

A production instruction such as “make this area look like [commercial game location]” is incomplete and unsafe.

Rewrite it as a Stillring-specific design problem and solution.

`docs/05_IP_GUARDRAILS.md` remains binding.

---

# 10. Approval labels for visual boards

Every board should carry one of these labels:

- **EXPLORATION** — visual questions are still open.
- **DIRECTIONAL** — approved direction, details may change.
- **PRODUCTION REFERENCE** — approved to guide production under written authority.
- **HISTORICAL / SUPERSEDED** — retained only for decision history.

No agent may infer that the newest-looking board is automatically the current authority.

---

# 11. Final rule

> **References help us see the answer. The repository must still be able to say the answer in words.**

A competent artist, designer, technical artist, or agent should be able to continue Stillring without needing access to the original chat where the visual direction was discovered.
