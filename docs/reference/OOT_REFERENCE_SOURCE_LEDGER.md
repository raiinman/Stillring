## Developer commentary / primary-source design material

### Z-targeting and multi-enemy choreography

Nintendo / Iwata Asks:
- https://iwataasks.nintendo.com/interviews/3ds/zelda-ocarina-of-time/1/2/
- Nintendo UK mirror: https://www.nintendo.com/en-gb/Iwata-Asks/Iwata-Asks-The-Legend-of-Zelda-Ocarina-of-Time-3D/Vol-2-Original-Development-Staff-Part-1/3-Let-s-Go-to-Toei-Kyoto-Studio-Park-/3-Let-s-Go-to-Toei-Kyoto-Studio-Park--231680.html

Research conclusion: targeting solved a coupled camera/attack/readability problem, and the team deliberately constrained multi-enemy aggression so opponents would not all swamp the player simultaneously. For Stillring this means lock-on belongs to encounter architecture, not only camera code.

### Target feedback becoming fiction

Nintendo / Iwata Asks:
- https://iwataasks.nintendo.com/interviews/3ds/zelda-ocarina-of-time/1/3/

Research conclusion: a targeting marker evolved into an in-world navigation/fairy presentation. Stillring should similarly ask whether important combat feedback can be integrated into Orra's fiction without harming readability.

### Contextual auto-jump

Nintendo / Iwata Asks:
- https://iwataasks.nintendo.com/interviews/3ds/zelda-ocarina-of-time/4/4/

Research conclusion: auto-jump was used to reduce explicit input and let terrain context control the resulting movement/pose. Stillring does not need to copy auto-jump; the relevant principle is that contextual traversal can simplify controls when player intent is reliable.

## What was intentionally excluded

- Video walkthrough footage as a production reference.
- ROMs, decompilations, reverse-engineered code, extracted maps, collision, textures, models, animations, sound effects, music, scripts, dialogue dumps, or game files.
- Master Quest room layouts as a source for Stillring dungeon geometry.
- Fan recreation assets.

## How future contributors should use this ledger

When referencing a source above, record only:

1. the **design problem** being solved;
2. the **abstract dependency/mechanic** used to solve it;
3. why the timing/placement works;
4. a Stillring solution that differs in fiction, geometry, interaction, presentation, and implementation.

If a task requires exact room geometry, dialogue, item appearance, melody, quest instructions, or scene staging from Ocarina of Time, stop: that is outside the purpose of this research corpus.
