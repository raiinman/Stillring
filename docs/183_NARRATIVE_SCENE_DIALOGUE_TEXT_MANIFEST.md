# 1. Purpose

This manifest converts Stillring's canon into estimateable narrative production.

A studio should be able to answer:
- how many canonical scene entries exist;
- which scenes remain playable versus staged;
- where major performance lives;
- which dialogue wording is protected;
- which scene/dialogue copy still requires writing;
- which ambient/world-state line families must exist;
- which 32 records must be authored;
- which credits consequences require text/performance support;
- which items depend on the unresolved VO model;
- which content is runtime/implementation work rather than narrative invention.

---

# 2. Production code legend

## Delivery class

- `NP-A` — embodied playable; gameplay/world action carries the beat.
- `NP-B` — playable performance; player remains active while authored dialogue/social performance matters.
- `NP-C` — walk/talk, work/talk, travel conversation.
- `NP-D` — hybrid bounded staging.
- `NP-E` — full cinematic / cinematic fragment.
- `NP-F` — quiet/free aftermath or low-pressure interaction.
- `NP-G` — credits/montage consequence presentation.

These are production classifications only. `docs/story/07` control labels remain canonical.

## Dialogue burden

- `DB0` — no required spoken scene beyond contextual efforts/short system lines.
- `DB1` — light contextual/ambient dialogue.
- `DB2` — authored scene conversation required.
- `DB3` — major performance scene; emotional/continuity burden.
- `DB4` — anchor-critical performance containing LOCKED/STRONG dialogue-anchor material.

## VO priority class

This is not a VO-scope decision.

- `VO-P0` — principal critical performance if selective VO exists.
- `VO-P1` — major recurring critical-path scene.
- `VO-P2` — named support / substantial regional scene.
- `VO-P3` — ambient/incidental.
- `VO-NONE` — written/nonspoken content.

## Variant class

- `CORE` — canonical authored beat.
- `CORE+STATE` — canonical beat with world/Setup/Payoff/completion-sensitive variants.
- `FLEX-NODE` — canonical regional/flexible-order node; not necessarily required in every minimal critical-path traversal.
- `OPTIONAL-DEPTH` — optional content may deepen the beat but may not carry mandatory explanation.
- `CREDITS-STATE` — consequence derived from current world/completion facts.

Safe to outsource after a production packet is approved:
- copy editing of bounded nonlocked text;
- incidental line drafting from exact region/state briefs;
- record-body first drafts from exact provenance briefs;
- localization;
- subtitle spotting;
- selected cinematic previs/blocking from exact scene authority.

Not safe to outsource as an open-ended invention task:
- principal story rewrites;
- new Maelor/Ilyra/Orin motivations;
- reveal-order restructuring;
- replacement of playable scenes with cinematics;
- new endings;
- new mandatory characters;
- ad hoc lore to fill perceived gaps without authority.

# 22. Narrative production blockers versus normal writing work

## Normal production writing — not an owner blocker

- final prose for INTENT scenes;
- supporting scene dialogue inside locked beat;
- ambient line variants;
- record body copy;
- world notice copy;
- journal summaries;
- subtitle segmentation;
- performance naturalization.

## Dependency blockers

- final VO selection affects recording/casting schedule, not whether scripts can be written;
- ship-language list affects localization production, not source-text authoring;
- final cinematic implementation affects shot assets, not scene identity;
- final runtime branch services affect implementation, not semantic condition definitions.

## Owner blockers

Only material canon/product departures or VO-scope selection where owner authority applies.
