# 05 — Original-IP / Clean-Room Guardrails

This is a production policy, not legal advice.

## Core rule

Project Stillring may learn from **abstract design principles** of prior games. It must create its own expression.

There is no “10% difference” safe harbor.

## Forbidden source material for implementation

Do not use:
- ROM files,
- decompiled or reverse-engineered commercial game source as implementation input,
- ripped maps,
- extracted models,
- extracted textures,
- extracted animations,
- copied dialogue,
- copied cutscene scripts,
- copied sound effects,
- copied music/melodies,
- trademarked logos or title treatments,
- fan-made traced recreations of copyrighted assets as a shortcut.

## Forbidden design behavior

Do not take a famous protected element and only:
- rename it,
- recolor it,
- mirror the geometry,
- change a small percentage,
- swap character species,
- alter a few notes,
- rearrange rooms while preserving the recognizable layout.

## Allowed inspiration workflow

### Step 1 — State the abstract player problem

Example:
“Third-person melee becomes hard to read when the camera and attacks are not oriented around a chosen enemy.”

### Step 2 — State the generic design technique

“Provide an explicit target-focus mode that changes movement/camera behavior.”

### Step 3 — Invent Project Stillring's implementation

Define our:
- camera distance,
- switching rule,
- reticle language,
- movement constraints,
- enemy group behavior,
- animation timing,
- accessibility behavior,
- UI presentation.

Now we have solved the same category of problem without cloning expression.

## Names and branding

Internal codename: `Project Stillring`.

Before public commercialization:
- search title conflicts,
- check relevant trademark databases,
- review logos/marketing for confusion risk,
- conduct an IP/legal review appropriate to the release plan.

## Art direction firewall

“N64-inspired” means constraints and craft language:
- low polygon budgets,
- compact textures,
- fog,
- strong silhouettes,
- limited material complexity,
- period-like animation economy.

It does **not** mean:
- copying a particular character silhouette,
- reproducing a recognizable dungeon room,
- tracing UI frames,
- repainting an existing texture,
- cloning a famous enemy with a different face.

## Audio firewall

No melodic interpolation of recognizable themes.

The game's sound identity should come from:
- metallurgy,
- bells,
- resonance,
- room impulse,
- mechanical percussion,
- regional instrumentation developed independently.

## Narrative firewall

Do not preserve a famous game's scene-by-scene plot and swap nouns.

Project Stillring intentionally differs through:
- no princess-rescue premise,
- no sacred royal bloodline protagonist,
- no three-artifacts-then-five-temples structure,
- no child/adult hero transformation,
- no evil king seeking a triangular sacred relic,
- no restoration of monarchy as the ending,
- no musical flute as the central interface,
- antagonist motivation centered on freezing change and grief,
- final resolution dismantling centralized sacred infrastructure.
