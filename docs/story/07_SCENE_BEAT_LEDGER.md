# Project Stillring — Scene Beat Ledger

**Status:** canonical critical-path scene production map  
**Related:** Issue #16, `docs/02_STORY_BIBLE.md`, `docs/12_100_PERCENT_ROUTE.md`, `docs/story/06_CHARACTER_ARCS_AND_RELATIONSHIPS.md`

This ledger breaks the mandatory story into stable production scenes/sequences.

A **scene** here may be a cinematic, a hybrid playable sequence, a walk-and-talk, or a gameplay chapter with scripted state changes. It is not synonymous with “cutscene.”

## Control labels

- **PLAYABLE** — normal player control is the narrative delivery mechanism.
- **HYBRID** — player control with bounded staging/dialogue/camera beats.
- **WALK/TALK** — constrained movement while characters converse/work.
- **CINEMATIC** — player control intentionally removed.

## Rule

If a scene contains important exposition but no one wants anything and the player does nothing, it is not finished.

# Critical-path scene count

Current ledger: **66 mandatory production scenes/sequences**, counting gameplay chapters and boss/reveal sequences as scenes when they have stable narrative state transitions.

The number may change during pacing work. Scene IDs should remain stable once implemented; removed IDs should be retired rather than silently reused for different scenes.

# Scene implementation rule

Before a scene is considered script-ready, production must record:

- start world-state requirements;
- participants and spawn/state rules;
- required prior knowledge flags;
- optional acknowledgement flags;
- player-control transitions;
- fail/reload checkpoint;
- objective state changes;
- dialogue asset IDs once written;
- end world-state outputs;
- downstream payoff IDs.
