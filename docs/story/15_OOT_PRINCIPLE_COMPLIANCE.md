# Project Stillring — Ocarina-of-Time Principle Compliance Audit

**Status:** completed structural compliance record  
**Reference:** `docs/reference/OOT_100_PERCENT_ANATOMY.md`

This document compares Stillring against **functional adventure-design principles** extracted from Ocarina of Time and Nintendo design commentary. It does not authorize copying protected expression.

The goal is:

> preserve the clarity, cadence, interconnection, recontextualization, and memorable recurrence that make a classic authored adventure flow — then go further by making Orra more socially alive and causally responsive.

---

# Final compliance results

## 1. Small home ownership — PASS
Brindle provides ordinary work, Orin, Tessa, First Ring preparation, optional village life, and visible revisit promises before catastrophe.

**Protection:** do not turn every opening object into ominous foreshadowing.

## 2. Leaving home expands scale instead of dumping lore — PASS
Road repair → Meridian ridge → Cairnspire queue widens the world through action and visible dependence.

## 3. Wider world ownership before repeated dungeon cadence — PASS
The final First Circuit physically establishes ordinary-life memories in all six regional cultures before Rootmere's full crisis.

## 4. Major tools are verbs, not trophies — PASS
Anchor, Glasslung, Temper, Vane, Mirror Nail, Palinode, and seam mode each solve immediate problems, support multiple systems, and reopen old spaces.

## 5. World-state pivot transforms known geography — PASS
Grand Ring changes places the player personally visited: Rootmere ferry/bell-oak, Saltreach fog harbor, Emberstep cooling court, High Aerie wind span, Mireglass reflection game, Cairnfall public sky.

## 6. Post-pivot agency returns quickly — PASS
Ilyra reunion establishes one practical lead, changed Brindle pays off prior setup choices, and the previously seeded Line Skiff restores mobility before the second half becomes oppressive.

## 7. Setup now, payoff later — STRONG PASS
The 12 setup/payoff chains produce authored later consequences without a hidden morality meter.

## 8. Optional systems braid together — STRONG PASS
Line Skiff/Drift Knots, testimony/Witness Interval, mastery trials/tool upgrades, Unstandard Tool specialists, Fault revisit waves, and community projects interlock rather than live in separate menus.

## 9. Side quests make people worth observing — PASS
The 24 repair contracts have named people, recurrence, and later consequences. The side-interaction rebalance prevents every optional scene from becoming a miniature infrastructure lecture.

## 10. Major dungeon cadence varies — PASS
Root Cathedral, Tide Foundry, Kiln of Names, High Aerie campaign, Bone Archive interlude, Palace Under Reeds, Fallen Orrery, Still-Cairn, and Null Meridian use different scales and narrative grammars.

## 11. Perception verbs create revisit waves — PASS
Palinode and Mirror Nail first teach new ways of understanding state/history, then reopen old regions, then become necessary in late synthesis.

## 12. Traversal transformation carries history — PASS
Line Skiff is seeded at Graymile with Tessa's prior experience before its changed-world payoff.

## 13. Main-story pressure alternates with optional freedom — PASS
The 100% route braids completion around story windows while explicitly suppressing cleanup nudges after Emberstep evidence, Grand Ring, Mercy Window, and Orin's confession.

## 14. Immediate objective stays clear while mythology remains mysterious — PASS
Post-Ilyra progression is one practical lead at a time: return to Brindle → find Tessa → investigate High Aerie's moving relation → follow rescue evidence → follow Mireglass contradiction → use Cairnfall to read Orin's signal → find Orin.

Motion, Memory, and Ending are experienced before being named and are not presented as an upfront three-item collection quest.

## 15. Antagonist influence is felt before the final fight — PASS
Maelor protects the Key, provides real technical help, shapes regional selection, worsens First Ring intentionally, manipulates the reference field, and continues affecting moving pockets after Grand Ring without becoming a constant taunting voice.

## 16. Final dungeon is the curriculum exam — STRONG PASS
Null Meridian recombines known tools/relations and introduces no new mandatory core language.

## 17. Final encounter resolves what the player has been doing — STRONG PASS
The ending mechanically uses the same principles practiced throughout the game: change can remain coordinated, memory can remain knowable, and useful states can end.

## 18. Ending returns attention to ordinary life — STRONG PASS
Playable Brindle, unresolved family relationships, familiar regional people, imperfect bells, and Tessa's road return the mythic story to human scale.

## 19. Living-world extension beyond the reference — PASS TARGET LOCKED
World Pulse state changes, regional community bibles, recurring side NPCs, life-bearing interactions, and save-state-sensitive Listener/credits callbacks make Orra continue existing when Neris is absent.

This is one of Stillring's core differentiators and must survive production cuts wherever possible.

# Non-copy boundary

Following these principles never authorizes:
- copying Ocarina's story order scene-for-scene;
- recreating its child/adult plot device;
- sacred-object collection analogues;
- copied dungeon layouts/themes or map correspondence;
- familiar character-role renames;
- musical-key progression;
- copied NPC quest dependencies;
- item/enemy/boss visual or functional clones;
- dialogue/cutscene reconstruction;
- use of ROMs, decompilation, extracted maps, or ripped assets.

Stillring uses the **design jobs**, then solves them through Orra-specific infrastructure, people, tools, politics, geography, and themes.

The test remains simple:

> If the design can be described as “the same Zelda thing with different nouns,” redesign it.
