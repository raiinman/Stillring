## Tool design rule

Every major tool must have at least:
- one traversal verb,
- one puzzle verb,
- one combat verb or tactical interaction,
- at least one later-game recombination with an older tool.

## Boss design rule

A boss should primarily test the mechanic taught by its dungeon.

If the optimal strategy ignores the dungeon mechanic and simply repeats basic attacks for several minutes, redesign the boss.

## Region completeness checklist

A production-ready region requires:
- visual landmark,
- traversal identity,
- ambient sound identity,
- local social conflict,
- at least 3 enemy archetypes or meaningful variants,
- one optional mini-quest chain,
- one optional secret using an earlier tool,
- major dungeon,
- boss,
- new tool/mechanic or narrative capability,
- pre/post-catastrophe state,
- performance pass,
- save/reload regression pass.
